Требования:
 -PHP 7.4+
 -GDlibrary
 -phpCurl
 -mod_rewrite

Команды удалённого управления:
 /?clean - очистит кеш
 /?api=getcounter - получить данные счетчика
 /?api=getcounter&delete - получить данные счетчика и удалить их с сайта
 
Функции:
 page404(); - выводит 404 страницу, останавливает дальнейшую работу скрипта
 r_title(); - выводит тайтл
 r_description(); - выводит description
 r_keywords(); - выводит keywords
 p_tags(); - выводит анкор-ссылки на теги
 p_thumb(); - выводит ссылку на превью картинку из папки /static/, может принимать параметр [имя файла]
 p_views() - выводит кол-во просмотров страницы, принимает 2 параметра [время создания страницы] и [тайтл страницы]
 r_loadfile(); - выводит содержимое файла, принимает параметр [имя файла от папки /data/]
 r_categories(); - возвращает массив с категориями
 p_relatedPages(); - возвращает массив с похожими страничками
 r_fluidvids(); - выводит код fluidvids.js (делает embed адаптивным)
 r_footstring(); - выводит строку с копирайтом
 p_rating(); - выводит блок рейтинга для rich snippets
 r_pagenavi(); - выводит постраничную навигацию, принимает следующие параметры [кол-во выводимых страниц] [тег оборачивающий ссылку] [класс активной ссылки] [тег текущей странички] [классы для ссылки]
 cloakBox(); - выводит данные из data/cloakBox.php, срабатывает только при использовании специального линка
 
Метки шаблонизатора заголовков:
 #KWD# - основной ключ
 #SKWD# - второстепенный ключ
 #TAG# - случайный тег
 #SNM# - имя сайта
 #ST# - основной тайтл сайта
 #DLM# - глобальный разделитель
